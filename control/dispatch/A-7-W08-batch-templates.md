## 为团队解除什么阻塞

成员做完一课以后，"再做一批 50 词"目前还是要重复劳动：重复选词、重复配媒体、
重复等同一批失败后全部重跑。Agent 也不能无人值守地提交一批活。
本任务把**批量计划**和**可共享模板**做出来，让"再来一批"变成一次提交，
并且失败只重做失败的那部分。

## 要求

1. **固定 `record_id` 的批次计划**：一个批次 = 一段固定选区 + 固定分包规则 + 固定模板版本；
   计划是**只读产物**，可打印/可复查（谁、哪些词、预计费用单位与磁盘占用）。
2. **每批独立实例**：每批创建自己的工程实例（不共享可变状态）；批次之间不互相影响，
   一批失败不拖垮其他批。
3. **模板共享与升级**：模板可被多批引用；**模板升级只影响显式升级的批**，
   且要保留成员手改（升级冲突要能对照、能撤销）。
4. **局部重做**：重跑只重做失败/变化的项，**不清空全部缓存、不重复合成未变化的音频**。
   要有实测数字证明"改一个词只影响该词需要的产物"。
5. **预检**：提交前报告命中/缺失、费用单位、磁盘与目标兼容性；缺媒体/字体/音色给
   结构化 `NEEDS_INPUT` 与可执行修复项（沿用 W05 的口径），**不要弹窗**。
6. **模板包安全**：模板包不含密钥、不含绝对工作路径、不含可执行脚本；
   换根路径的副本要能直接导入。

## 验收（必须真跑并贴结果）

1. **真实 50 词一批**（`provider.kind=local`，零网络——生产已暂停，不要用真实 TTS）
   出齐三产物，过 `tests\acceptance\accept_range.py --cleaning v2 --pixels first`（或你的等价判定）。
2. **离线多包故障样例**：少包 / 漏最后一包 / 单批失败 → 恢复只重做失败项（贴重做范围与未动范围）。
3. **改一个词**：只影响该词需要的产物；给出缓存命中/未命中与调用数的实测数字。
4. **模板升级**：成员手改保留、冲突可撤销（给前后对照）。
5. **模板包**：换根路径副本可导入；扫描证明无密钥/无绝对路径/无脚本。
6. 全量：`python -m pytest tests`（默认口径）。
