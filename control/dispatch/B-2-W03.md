## 交付物

1. **`LayoutSurface` 接口**（`word_video/layout/`）：给定画布尺寸/DPI/字号/文本/角色样式，
   返回每个文本对象的位置与包围盒（含溢出判定）。**这是 C 的预览必须复用的唯一排版实现**；
   接口先交小而稳定的一版，冻结后告诉 H0。
2. **三条导出**（`word_video/exporters/`）：同一 `RenderPlan`/`CuePlan` →
   ① MP4（自有渲染，不依赖剪映 GUI）；② 五轨 SRT；③ 可编辑剪映草稿（独立可编辑对象 +
   所需媒体）。毫秒/微秒只在导出适配器边界用 `ticks_to_*` 换算一次。
3. **一条命令**：从 `project.json`（A 的 `load_project`）+ 媒体探测（你的 `MediaInfo`）→ 三产物。
   与旧 CLI 兼容：旧的 `submit/start` 链路**必须保持可用**（旧归档可复现是本任务的红线）。
4. **测试（必须真跑并贴结果）**：
   - 真实三词（151-153，含 IPA 与较长释义）出齐三产物；
   - 逐角色文字与时间核对（不是抽样：每个角色的每个片段都要断言）；
   - 首帧/中帧/尾帧 + 教学阶段切换帧的像素探针（你说清用了什么方法）；
   - 草稿侧：文字/各条配音/背景都是独立可编辑对象，字体资源齐；
   - **旧链回归**：用 `data\fixtures\p1-有片头.json` 跑旧链路，产物用
     `tools\m0\accept_range.py --cleaning legacy --pixels all` 判定 **PASS**。
