## 六步（约 5 分钟）

1. 打开剪映 → 打开草稿 `单词速记_M0三词待验_20260916`：确认**文字不是图片/不是烧录**，
   点一下能选中、能改字。
2. **改一个词**：把第一个英文单词改成任意临时文字（例如 `evaluateX`），看是否只影响这一段。
3. **移音标**：把某一条音标文字上下拖动，确认只有它动、英文/中文不动。
4. **换一条配音**：把某一条中文配音删掉或换成别的音频，确认时间线上其他对象不被带走。
5. **换背景**：替换背景视频/图片，确认文字与配音保留。
6. **保存 → 关闭 → 重开**：确认改动还在；然后**导出 5 秒**并连续播放，确认画面与声音正常
   （不该出现中文释义被念出词性，例如"n. 苹果"）。
