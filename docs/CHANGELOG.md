## 2026-09-17 — 预览改为"模板效果预览"；编辑器可按角色调样式

- **预览只做模板效果**：只画文字层（与成片**同一套排版**）+ **背景一张静帧**；不再解码视频、不建低清代理、
  不做后台分段编码、**预览不出声**、**软件内不做时间线编辑**。
  实测（同机同请求）：打开工程到看见文字 **19s → 7s**（文件缓存热时 3s）；**静置 CPU 43.2% → ≈0%**；
  常驻内存 391MB → **288MB**；预览进程内解码/编码子进程 **0 个**。
- **三产物未变**（逐字节对照同一请求）：`video.mp4` **相同**、**五轨 SRT 5/5 相同**、`captions.ass` 相同、
  `timeline.json`/`speech.json` 归一化运行目录后相同、文件数 326 一致。
- **编辑器可以按角色调样式**：右侧新增**样式角色下拉**（英文 / 音标 / 中文释义 / 片头倒计时…），
  可调**字号 / 颜色 / 位置（x、y）**，改完**预览立刻反映**，可一键恢复默认，并支持撤销/重做。
- **软件内的时间线编辑控件下线**：起止时间、速度、绑定/解绑、恢复语音长度、在播放头处拆分不再显示；
  播放/暂停/定位/进度、保存、撤销重做、模板/高级模式保留。**改时间、改样式请在剪映草稿里做**（草稿可编辑不变）。
- 顺手把窗口的状态轮询定时器改成事件驱动，空闲时不再有周期性刷新。
- 仍未验：真实窗口观感与目标机（普通核显轻薄本）、成员机 DPI 表现；最终"好不好看"需人眼看。
