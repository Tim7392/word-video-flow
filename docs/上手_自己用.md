## 1. 打开软件

**成员包（推荐，不依赖开发环境）**：
双击 `D:\1\1-AI_workflow\word_video_flow\out\packages\word-video-member-0.3.0\单词视频.cmd`
→ 直接打开编辑器（同一个包里的 CLI 入口仍在，Agent 用）。

**开发机源码态（等价，便于看日志）**：
```powershell
& D:\1\1-AI_workflow\word_video_flow\runtime\venv\Scripts\python.exe -m desktop
```

## 2. 准备一份"请求"（词表 + 范围 + 已有配音）

编辑器目前**从请求 JSON 导入**（词表+范围直接建课在排期里）。已给你放好一份 50 词的：

| 用途 | 路径 |
|---|---|
| 请求文件（50 词，501-550） | `data\fixtures\tim-501-550.json` |
| 它用的词表 | `data\wordlists\四级核心1500词_已清理.txt` |
| 它引用的配音 | 归档 `范围501-700-1080p素材\wv-…\0501-0550\audio-cache\**\original.*`（**本地已有，零网络**） |

想换范围（例如 551-600），用同一条命令生成即可（`--archive-batch` 换归档里对应批次目录）：
```powershell
& D:\1\1-AI_workflow\word_video_flow\runtime\venv\Scripts\python.exe `
  D:\1\1-AI_workflow\word_video_flow\repo\tools\build_replay_request.py `
  --archive-batch "D:\单词速记自动化_测试归档_0915\范围501-700-1080p素材\wv-2bdf4a5ba1e77f1d99a2d369\0551-0600" `
  --output "D:\1\1-AI_workflow\word_video_flow\out\tim\551-600" `
  --key "tim-551-600-r1" `
  --fixture "D:\1\1-AI_workflow\word_video_flow\data\fixtures\tim-551-600.json" `
  --wordlist "D:\1\1-AI_workflow\word_video_flow\data\wordlists\四级核心1500词_已清理.txt"
```

## 3. 在编辑器里做一课

1. 菜单 **文件 → 从请求导入**（选第 2 步的请求 JSON）→ 选一个**工程目录**（自己起名，例如 `D:\1\...\out\tim\project-551-600`）。
2. 左侧点选片段：**默认只选一个**；拖动/修剪只动它；要整组动就显式框选或用整组操作。
3. 选中文字片段可在右侧改**字号/颜色/位置**（改字号**不会**重新合成配音）。
4. 预览：画布按 720p30 档；**首次打开要等**（见上文性能说明），之后拖动很快。
5. 点**导出** → 三产物一起出。
