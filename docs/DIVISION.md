# 分工指南（R1.1 合并版）

共同原则见 `AGENTS.md` 首节。**分工只是协作边界，不是各自追求局部最优的理由。**

## 1. 角色与唯一写入主范围

| 角色 | 唯一写入主范围 | 负责任务 | 交付时必须同时考虑的整体影响 |
|---|---|---|---|
| A 核心与自动化 | `word_video/domain`、`application`、`storage`、`cli`、公共契约 | W01、W05、W08 | 同一业务规则供 UI/CLI/导出消费；接口复杂度、保存/幂等、局部复算不能让其他模块重复实现或让成员多操作 |
| B 媒体与交付 | `word_video/{media,voices,layout,exporters}`、迁入的旧视频修复副本 | W02、W03、W07 | 完整媒体/音频正确性、原生可编辑、端到端等待；局部提速不换成重复 TTS、无限缓存或额外磁盘副本 |
| C 桌面与发行 | `desktop/`、`preview/`、`packaging/`、`legacy_adapter/` | W04、W06、W09、W10 | 非开发成员可操作、核显资源、包装与故障恢复；不把环境修复交给成员，不让视觉效果抢占生产资源 |
| QA 独立验收 | `tests/acceptance/`、性能测试入口、验收结果 | W11 + 每次集成反例 | 固定输入下的完整 UI/CLI 生产、关键失败恢复与资源证据；不用测试数/单模块 PASS/不可复现数字替代可用性 |
| H0 主控 | 根配置、锁文件、AGENTS、STATUS、集成分支与 push | W00、派工、协调接口与合并 | 集成后检查全流程、跨模块接口与资源分配；局部均通过但全局受阻时协调最小修复，不把问题甩给下一阶段 |

补充：开发者可写本模块单测；**QA 不能为通过而修改生产实现**。公共 schema 由 A 单写，
消费者（B/C/QA）用同一版本。B 需要 UI 页面时给 C 组件需求，不越界改 `desktop`。
一个角色不一定常驻一个子 Agent：任务完成就结束，省上下文与本机资源。

## 2. 派工口径

H0 每次派工写清"**为团队成员/Agent 解除什么生产阻塞，做到什么即可**"，而不是只列要写的模块，
并必须带上：任务目标、基础 commit/接口版本、绝对 worktree、可改范围、输入夹具、
验收点（含相关跨模块影响）、禁止事项、核心原则（子 Agent 不继承父会话上下文）。
不为了让所有 Agent 有活干而拆碎任务、制造等待或同时争用媒体资源。

需要新增依赖、重复数据、额外并行或跨模块重构时：先问更简单方案是否足够，
再说明实际收益与主要代价；有证据且在既有预算内的局部取舍可以接受，
不擅自改已批准标准。不能证明需要的大改先不做。

## 3. 并行波次（静态清单见 `control/tasks.json`）

- **第一波**：H0 完成路径/隔离；A=W01；B=W02；QA=坏样本。C 可读代码，不另开超过上限的写进程。
- **第二波**：A=W05；B=W03；C=W04。接口先交小而稳定的一版，三者并行，不等全部文档或全系统实现。
- **第三波**：A=W08；B=W07；C 先交 W09 早期包再推进 W06。QA 持续复验集成。
- **第四波**：C=W09 硬化/W10；A/B 修各自缺陷；QA=W11。

## 4. 隔离与资源纪律

- 每个子 Agent 独立 worktree + 私有 tmp；同一套锁定依赖只由 H0 改。
- 共用 venv 时禁止并发 editable 安装/依赖更新；从当前 worktree 显式加载源码。
- 合并后 QA 在集成目录复跑，不能只相信各分支测试。
- 子 Agent 用默认模型，最多一级派发；停止后确认没有继续写入再回收目录。
- 模型调用可并行；**重编码、长时间性能/GUI/剪映测试独占本机槽位**。
- 8GB 目标机：默认 1 个重导出任务，最多 1 个预览会话；不把 3 开发当成 3 路 4K 渲染。
- GitHub 由 H0 统一 push；不 force push，不覆盖未提交用户工作，不自动开公开仓库。

## 5. 子 Agent 禁止事项（每次派工都写）

- 不 force push、不改受保护路径（旧引擎原树、旧归档、旧剪映草稿、M0 证据、他人 worktree）。
- 不递归派子 Agent；不改共享 venv/依赖；不动系统设置；不装系统组件。
- 不降低验收阈值、不删断言、不用 SKIP 或旧 PASS 顶替；不静默改默认行为/字体/音色/输出规格。
- 不把密钥、真实素材、用户工程、音频缓存、无分发依据字体写入仓库。
- 不凭空扩展任务范围；发现更大问题记入交付报告交给 H0 裁决。
