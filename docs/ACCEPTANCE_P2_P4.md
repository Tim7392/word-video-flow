# P2/P4 集成验收清单（H0 用；W05/W06 合并后逐项跑并贴证据）

目的：把"软件对成员可用"拆成**可执行的检查**，避免到验收时临时拼凑口径。
每项都必须有命令/操作步骤 + 真实输出；**做不到就写"待验"，不许用"看起来没问题"顶替**。

## A. Agent 自动化（W05 交付后）

| # | 检查 | 判据 |
|---|---|---|
| A1 | `capabilities` / `doctor` / `project` / `voice` / `template` | stdout **单个 JSON**、日志走 stderr；`doctor` 能报字体与 ffmpeg 来源 |
| A2 | `batch plan` | 只预检/估算：**不合成、不发布**（跑完检查输出目录无新产物） |
| A3 | `batch submit` 幂等 | 同键同请求 → 返回**同一个 job id**；同键不同内容 → 冲突错误；重试已完成项**不重复扣费、不覆盖成果** |
| A4 | `job status/cancel/resume` | 取消后**不发布**任何正式产物；resume 从断点继续而不是重做全部 |
| A5 | `artifacts` | 列出的路径真实存在且与 `complete.json` 一致 |
| A6 | 非交互 | 缺信息时返回 `NEEDS_INPUT` + 可执行修复项，**不弹对话框**；非法参数也是结构化 JSON + 非零退出码 |
| A7 | 崩溃/强杀对账 | 杀 worker 后主控能标记/恢复，**不出现"半个产物被当成功"** |

## B. 成员可用（W06 合并后）

| # | 检查 | 判据 |
|---|---|---|
| B1 | 三词全流程 | 从导入词表到出齐三产物，**全程不手改 JSON** |
| B2 | 单片段编辑 | 默认单片段；拖动/修剪只影响选中对象（逐对象断言 tick）；整组联动是显式操作且列出跟随者 |
| B3 | 拆分 | `can_split` 决定按钮态；拆背景 → 导出**两段都在**（我裁定的多段背景）或明确拒绝；拆文字/词角色 → 结构化拒绝 |
| B4 | 改字号 | 字号面板 → 产物里确实变大、**其它角色不变**、**TTS 调用 0** |
| B5 | 撤销/保存/重开 | 撤销回到原状（逐对象）；重开无丢失、无残留临时文件；模式切换不改业务数据 |
| B6 | 错误定位 | 缺媒体/字体/音色/过期工程 → **定位到词/角色 + 可点修复**，不是只有"确定"的弹窗 |
| B7 | 预览与成片一致 | 画布用 `LayoutSurface`（经 `merged_styles`）；320×180 与 1920×1080 锚点/行位置一致 |
| B8 | 预览资源 | 720p30 档位下首帧/seek 达标（记录实测；**目标核显机未测就写未测**） |

## C. 交付与恢复（W09/W10 交付后）

| # | 检查 | 判据 |
|---|---|---|
| C1 | 成员包 | 清洗环境（PATH 仅系统目录、无 Python/FFmpeg/凭据）跑通三词；`VERSION.txt` 的 commit 能在 `git log` 对上 |
| C2 | 包内扫描 | 无带值密钥、无真实素材、无音频缓存、无全量词表 |
| C3 | 路径健壮性 | 中文/空格路径；无 D 盘时明确选择其他数据盘而**不偷偷写 C** |
| C4 | 停止/取消/磁盘满 | 各自有可恢复行为，不留"自称完成"的记录 |
| C5 | 旧字幕适配 | 同词表/选区/分包/计时参数下**新旧五轨 SRT 内容与毫秒等价**；新旧入口失败互不拖累 |
